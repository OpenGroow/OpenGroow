# Postiz analytics reference (test fixture)

A copy of the Postiz Analytics Adapter package from the hub
(`groowhub/packages/analytics/postiz`), used only by the core's tests (the hub
chain test packs, serves, installs and loads it). It is not a workspace
package and is never shipped. Update it from the hub when the adapter changes;
the adapter's own contract tests live in the hub.
