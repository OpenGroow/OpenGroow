# ADR-035: Verify and select the Instagram account inside the Android Plugin

**Status:** Accepted

Each Social Engagement Agent represents one Instagram account, while multiple Agents may share one Execution device. Once, at the start of each Run, before entering Reels, the Android Plugin must verify that the Active Instagram account matches the Agent's configured handle and switch accounts when needed; it must not repeat this account flow for every post or scroll. The existing `instagramHandle` requirement remains the target identifier; verification trims whitespace, removes an optional leading `@`, and compares case-insensitively. This is exposed as one guarded semantic action (for example, `ensure_account`) rather than a sequence of raw UI actions in the Agent instructions, so the invariant is enforced below the model. If Instagram is relaunched or the screen leaves the expected session state during a Run, the account check is performed again before resuming. Only accounts already connected and selectable in Instagram are supported; if the account is unavailable or the post-switch identity cannot be confirmed, the Run produces the Social Engagement Template's declared blocker before any like or comment. This keeps account credentials and ambiguous UI states out of the Agent and prevents engagement under the wrong identity.
