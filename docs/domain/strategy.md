# Strategy

### Strategy Agent

The Agent that decides what to do next from how published content performed. It is an ordinary Agent Template, activated per Project like any other, **one per Project**, and never activated automatically. It reads; it never acts: its only output is a **Plan** that a human reviews (ADR-081).

It runs through a **Schedule** (weekly by default, adjustable) and can be launched on demand ("Run now"). Each run is an ordinary Mission of a `plan` Mission type, with the normal cycle `todo → doing → to_validate → done`.

_Avoid_: orchestrator, system agent. It does not run the other Agents; it only proposes Missions.

### Plan

The deliverable of a Strategy Agent Mission: a list of at most **5 Plan items**. It is reviewed like any other Artifact.

- **Plan item**: one Mission the Strategy Agent proposes (type, payload, the reason, the figures that justify it). It is not a Mission until the Plan is approved.
- **Approve** creates and launches the Missions of the items the user left selected, exactly as if the user had created them by hand. Every item starts selected.
- **Declined item**: an item the user unselected. It is recorded on the Plan Mission and read by the Strategy Agent at its next run.
- **Reject** asks for a revision: the user gives a feedback and the Strategy Agent plans again, in a new Run of the same Mission (the usual reject of every reviewable Mission).
- A Plan item is checked twice with the same rules as a manual Mission creation (active types, publishable channels, scheduling): when the Plan is received, and again at approval, because the Project may have changed in between.

The Strategy Agent has no other memory: its history of Plan Missions, with their declined items and feedback, is what it reads.

### Internal MCP

The MCP server OpenGroow itself serves from Convex (ADR-080). A Template declares it among its `mcpServers` like any other server and lists the tools it may call. It is read-only in V1: analytics summary, Publications, Missions, Brand Core, and the Mission types the Project can activate.

An Agent reaches it with an **Agent token**, generated at activation and bound to its Project. Convex accepts it only while that Agent has a Run in `running`.

_Avoid_: calling it a Run token; it is the Agent's `apiKey` (ADR-017), generated by OpenGroow instead of entered by the user.
