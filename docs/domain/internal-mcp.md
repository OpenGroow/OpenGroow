# Internal MCP

### Internal MCP

The MCP server OpenGroow itself serves from Convex (ADR-080). A Template declares it among its `mcpServers` like any other server and lists the tools it may call. It is read-only in V1: analytics summary, Publications, Missions, Brand Core, and the Mission types the Project can activate. Its readers are Agents that need OpenGroow's own data (the Strategy Agent is the first planned).

An Agent reaches it with an **Agent token**, generated at activation and bound to its Project. Convex lets it list the declared tools at any time, and accepts it to call a tool only while that Agent has a Run in `running`.

_Avoid_: calling it a Run token; it is the Agent's `apiKey` (ADR-017), generated by OpenGroow instead of entered by the user.
